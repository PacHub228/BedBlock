# Bedblock

Плагин для сервера Minecraft (на базе Spigot/Paper), который добавляет элемент опасности при попытке сна.

## Описание
Когда игрок пытается лечь в кровать, кровать мгновенно ломается (обе её половины), проигрывается звук и частицы, а игроку отправляется предупреждающее сообщение о том, что спать в этом мире слишком опасно.

## Возможности
*   Автоматическое прерывание попытки сна.
*   Уничтожение кровати целиком (обе половины блока).
*   Звук и частицы при срабатывании.
*   Настраиваемое сообщение игроку.
*   Гибкая настройка через `config.yml`.

## Установка
1. Скачайте последнюю версию плагина (`bedblock-1.0.jar`).
2. Поместите `.jar` файл в папку `plugins` вашего сервера.
3. Перезапустите сервер.

## Сборка
```
mvn clean package
```
Готовый `.jar` появится в `target/bedblock-1.0.jar`.

## Конфигурация (`config.yml`)
```yaml
# Ломать ли кровать при попытке сна (true) или просто запрещать сон (false)
break-bed: true
# Звук и частицы при срабатывании
effects: true
# Сообщение игроку (& для цветов)
message: '&cСпать в мире слишком опасно!'
```

## Команды
| Команда            | Описание                      |
|--------------------|-------------------------------|
| `/bedblock reload` | Перезагрузить конфигурацию     |

## Права
| Право              | Описание                              | По умолчанию |
|--------------------|---------------------------------------|--------------|
| `bedblock.bypass`  | Позволяет спать (обход блокировки)     | `false`      |
| `bedblock.reload`  | Доступ к `/bedblock reload`            | `op`         |
